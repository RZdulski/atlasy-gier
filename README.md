## Aktualizacje

Aktualizacje zapisujemy w prywatnym repozytorium, w gałęzi `main`, katalogu głównym. Nie włączamy publicznych Pages ani nie zmieniamy repozytorium na publiczne. Wcześniejsze wersje można odnaleźć w historii commitów. Aby korzystać z najnowszej wersji interaktywnej, pobierz aktualne pliki HTML.

Pakiet powstaje w lokalnym projekcie przy pomocy `publikacja-github/przygotuj.py`, po przebudowie katalogów źródłowych. Repozytorium zawiera gotowe pliki publikacji, a nie cały lokalny warsztat badawczy.
