## Aktualizacje

Publikacja GitHub Pages: gałąź `main`, katalog główny. Każdy commit zawierający nową wersję plików uruchamia aktualizację strony. Adresy obu katalogów pozostają stałe; wcześniejsze wersje można odnaleźć w historii commitów.

Pakiet powstaje w lokalnym projekcie przy pomocy `publikacja-github/przygotuj.py`, po przebudowie katalogów źródłowych. Repozytorium zawiera gotowe pliki publikacji, a nie cały lokalny warsztat badawczy.
